# Release Notes - v0.6.1

## Section Photo Upload Hotfix

v0.6.1 restores direct photograph upload within every operational report section while retaining the Quick Entry capture path introduced earlier.

### User-facing changes

- Adds **Add photographs** to the Site photographs and attachments card in each operational section.
- PHOTO-type guided discovery prompts now offer **Add photo to this section** instead of forcing navigation to Quick Entry.
- Supports one or multiple photographs in a single upload action.
- Supports native mobile photo selection/camera options through the browser image picker.
- Adds an optional caption/observation that is stored with the uploaded evidence.
- New direct uploads are attached to the current section, classified CONFIDENTIAL, and included INLINE by default.
- Reviewers can still mark individual photographs as Supporting only after upload.
- Offline section-photo capture uses the existing evidence queue and synchronizes when connectivity returns.
- Quick Entry remains available and unchanged.

### Scope

This is an interim hotfix only. It does not alter the v0.6.0 AI observation model, prompt rules, version-history model, or Cloud Inventory solution-intelligence roadmap.
