# v0.8.11 Release Notes

v0.8.11 simplifies operational report pages around the Current Operations Narrative.

- Discovery Questions are hidden by default and revealed as a read-only question list.
- Per-question answer/photo-entry controls are removed.
- Discovery Questions and AI History automatically reset closed after navigating to another report screen.
- Per-section Demo Priority display/collection is retired, and legacy priority rows no longer influence active demo-plan generation/readiness.
- Dedicated approved functionality mapping displays are removed from operational pages while governed mappings remain available internally.
- The AI Assistance inspector is replaced by an on-demand AI History panel with review status/content and permitted review actions.
- No database migration or new Render environment variable is required.
