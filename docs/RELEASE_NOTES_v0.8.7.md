# v0.8.7 Release Notes

- Adds administrator role editing.
- Replaces Delete User with Active/Inactive lifecycle controls.
- Deactivation revokes sessions while preserving roles and memberships.
- Reactivation restores access using the existing identity and password.
- Collaboration user selectors show active users only.
- Converts legacy v0.8.6 DELETED user rows to INACTIVE.
- Retains v0.8.6 password reset, photo-AI retirement, speech preferences, and configuration intelligence unchanged.
