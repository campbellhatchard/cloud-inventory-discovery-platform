# v0.8.9 Release Notes

## Unified Current Operations Narrative

- Quick Entry notes now write directly into Current Operations Narrative.
- Observation, Pain Point, Risk, Gap, Strength, and Opportunity are retained as editable narrative subheadings.
- The separate Findings card and Add Finding UI are retired.
- Manual narrative edits resynchronize the internal typed classification index.
- Superseded classifications remain in history and invalidate mappings tied to obsolete wording by marking them STALE.
- Existing v0.8.8 section findings are migrated into the narrative.
- AI observation wording is instructed to preserve user-selected classification headings.
- Report Preview and generated documents no longer duplicate narrative content in a second Current-State Findings section.

No new Render environment variables are required.
